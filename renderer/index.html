“Approve always” rules for this project

        

        
Commands run as you, with your permissions. File tools are limited to the project folder; commands are not. API keys are stored in your Mac Keychain.

        

        

      

    


    

      
Signing in is optional. GitHub lets the app push, pull and open pull requests for you. Google and Apple only identify you on this Mac: this app has no cloud service, so they do not unlock anything else.


      

        
GitHub

        

        

          
          
        

        
GitHub setup (one time)
          
Create an OAuth App at github.com → Settings → Developer settings → OAuth Apps. Tick Enable Device Flow. Any homepage URL works. Paste its Client ID here. No secret is needed.

          

        

        

      


      

        
Google

        
Google setup (one time)
          
In Google Cloud Console create an OAuth client of type Desktop app and paste its Client ID and secret. (For a desktop app Google calls the secret “not confidential”.)

          

          

        

        

      


      

        
Applenot available yet

        
Sign in with Apple needs a paid Apple Developer account and a web address on your own domain for Apple to send you back to; Apple does not accept a local address. That cannot be set up inside this app alone, so the button only explains this. If you publish the app on the Mac App Store later, the native Apple sign-in can be added then.

Skills

    
A skill is a folder with a SKILL.md file that teaches the agent how to do one kind of task. The agent sees the list and loads a skill when the task matches. Skills from ~/.claude/skills and from .agent/skills or .claude/skills inside a project are picked up too.
